# NVivo Thematic Coding Framework

## Description

Systematic protocol for thematic analysis and intercoder reliability in OSH qualitative research. NVivo is a qualitative data analysis software used for coding, organizing, and analyzing textual data.

## Origin and development

Not reported in the extraction.

## What it measures

- Thematic analysis
    
- Intercoder reliability
    
- Qualitative coding
    

## How it is applied

Qualitative data (interviews, focus groups, documents) are imported into NVivo and coded according to a thematic framework. Intercoder reliability can be assessed.
